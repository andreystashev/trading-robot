# Безопасность и публикация

Реальный торговый контур отключён: `SANDBOX=false` приводит к отказу запуска.
Sandbox всё равно содержит ваш токен, идентификаторы счетов и историю действий.
Не публикуйте их вместе с исходниками.

- Храните токен в `trading_bot/.env` или переменных процесса. В репозитории
  должен быть только пустой `.env.example`. Не вставляйте токены в команды,
  URL, issue, снимки экрана или примеры кода. Уже раскрытый токен перевыпустите
  в кабинете T-Bank; удаления из Git недостаточно.
- Git ignore не удаляет уже отслеживаемые файлы и старые коммиты. Если секрет
  был закоммичен, сначала отзовите его, затем очистите историю репозитория.
- SDK 1.51.0 автоматически включает Sentry. Адаптер проекта отключает его DSN
  до входа в клиент: ошибки приложения остаются в локальных логах.
  При обновлении SDK этот механизм необходимо перепроверить.
- Логи маскируют токены и Bearer-строки, но могут содержать пути, счета и
  брокерские данные. Поэтому все логи, состояния и отчёты считаются локальными.
- Панель предназначена для localhost. Host, Origin и ключ локальной сессии
  проверяются на управляющих запросах. Это не авторизация для публичного сервера.
  Не используйте внешнее перенаправление портов и не открывайте панель в интернет.
- JSON-профили задают разрешённые параметры; загрузка не исполняет Python-код.
- Compose монтирует `.env` как secret-файл при запуске. Это не шифрование файла
  на диске; доступ к компьютеру и Docker daemon также даёт доступ к данным.
- Docker build context задаётся списком разрешённых файлов. Нельзя заменять его
  копированием всей рабочей директории без проверки `.dockerignore`.
- TLS-проверки не отключаются. Исправляйте CA/DNS/прокси, а не обходите ошибки.

Перед публикацией запустите `python tools/check_publication.py` и создайте
архив через `python tools/export_source.py`. В Git-репозитории проверка также
отклоняет отслеживаемые служебные файлы. Она не заменяет ручной просмотр.

При сообщении об ошибке прикладывайте обезличенные данные: код исключения,
версию Python/SDK, действия для воспроизведения. Не прикладывайте `.env`.
